# TRND Station

Wholesale landing page for international snacks, sweets and drinks. Live at https://trndstation.com (GitHub Pages, main branch, root).

- Minimum order $200, free US shipping over $500
- contact@trndstation.com, 630-538-3934, Instagram @trnd.station

The site is one static page: `index.html`, with the design kit in `assets/`. Old page URLs (about, contact, faq, products, wholesale) redirect to sections of the home page. Product photos are hotlinked from Faire's CDN.
